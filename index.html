Row-scan bitmap editor • D82R.ASM-compatible output • 8086
No server required

1. Draw a glyph

The bitmap is interpreted as 16 rows × 16 columns. Each row generates two bytes: the first byte goes to XPA (columns 0–7), and the second byte goes to XPB (columns 8–15).

The generated assembly follows the supplied D82R.ASM row-scan structure.

2. Assembly output

Static output uses the same row-scan structure as D82R.ASM. Marquee output keeps the same XPA/XPB/XPC/PO interface.
