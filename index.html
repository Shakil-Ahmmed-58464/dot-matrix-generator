8086 16×16 Dot Matrix Studio

Visual bitmap editor • D82R-compatible row-scan assembly • binary TAB output
No server required

1. Draw a glyph

Hardware format:
Each row produces exactly two bytes.
First byte = columns 0–7 → XPA
Second byte = columns 8–15 → XPB
0 = LED ON, 1 = LED OFF
The TAB is written exactly as the bitmap is drawn. The assembly's REV procedure performs the bit reversal required by the hardware.

2. Assembly output

Static export follows the supplied D82R.ASM row-scan structure. The TAB is generated as binary and uses 0 = ON, 1 = OFF.
